If the copy button doesn't work

Some browsers block clipboard access inside an embedded page. Two fallbacks:

  1. Hit "Show text", click inside the box, then Ctrl+A and Ctrl+C (Cmd on a Mac). The box selects everything on click.
  2. Get the files from GitHub. They're committed on the claude/propwash-context-oz06mo branch as PROPWASH_COMPLETE.md and PROPWASH_ESSENTIALS.md in the repository root — open either one and use the download button.
